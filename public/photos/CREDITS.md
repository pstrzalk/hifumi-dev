# Photo credits and licences

Every image here is either an AI-generated image commissioned for this project
or a public-domain stock photograph from Pixnio. They are re-encoded for the
web (1 600 px long edge, q80, metadata stripped) and renamed to
content-descriptive slugs.

Re-encoding **strips EXIF/IPTC/XMP**, so this file is the only surviving record
of where each image came from. Keep it in step with the directory: adding a
photo means adding a row here.

No photograph of an identifiable real person remains in this set. Every face is
AI-generated.
